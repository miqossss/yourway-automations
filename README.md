# YourWay Automations

Kolekcja workflow'ów n8n (agenty AI, automatyzacje) tworzonych w ramach YourWay AI.

## Zawartość

- **Agenty sprzedażowe / lead gen**: Lead Gen Agent, Speed to Lead, Quote Agent (Detailing)
- **Obsługa klienta**: Agent pomocy klienta, Sekretarka AI, Chatbot AI Fotowoltaika
- **Wewnętrzne**: Agent Do Faktur, Agent Zarządzania Mailami, Analiza CV i pomocnik rekrutera, Agent Generowania filmów
- **EduFlow**: zestaw workflow'ów obsługujących platformę edukacyjną EduFlow (chatbot lekcji, sprawdzanie ćwiczeń, ocenianie odpowiedzi, wysyłka zaproszeń, przetwarzanie audio, generowanie materiałów z PDF)

## Uwaga

Pliki to eksporty workflow z n8n. Credentiale (OpenAI, Gmail, Supabase itd.) są referencjami do kont skonfigurowanych w instancji n8n — same w sobie nie zawierają kluczy dostępu. Przed uruchomieniem workflow w innej instancji n8n trzeba podpiąć własne credentiale.
