# YourWay Automations

Kolekcja workflow'ów n8n (agenty AI, automatyzacje) tworzonych w ramach YourWay AI.

## Zawartość

**Agenty sprzedażowe / lead gen / wyceny**
- Lead Gen Agent (Demo)
- Speed to Lead - Agent AI (test)
- Quote Agent - Demo (Detailing Samochodowy)
- Quote Agent - Demo (Przeprowadzki)
- Chatbot AI Fotowoltaika & Generowanie Leadów

**Obsługa klienta / reputacja**
- Agent pomocy klienta
- Sekretarka AI
- Auto-responder na opinie Google - Pizzeria

**Wewnętrzne / operacyjne**
- Agent Do Faktur
- Agent Zarządzania Mailami
- Analiza CV i pomocnik rekrutera
- Agent Generowania filmów
- Jakub Bujakiewicz - Chatbot (klient: trener personalny)
- ENERG Polska - automatyzacja

**EduFlow** (platforma edukacyjna - zestaw powiązanych workflow'ów)
- Chatbot Lekcji
- Sprawdzanie Ćwiczeń
- Ocenianie Odpowiedzi
- Wysyłka Zaproszenia
- Przetwarzanie Audio
- PDF do Materiału AI

## Uwaga

Pliki to eksporty workflow z n8n. Credentiale (OpenAI, Gmail, Supabase itd.) są referencjami do kont skonfigurowanych w instancji n8n — same w sobie nie zawierają kluczy dostępu. Przed uruchomieniem workflow w innej instancji n8n trzeba podpiąć własne credentiale.

Wrażliwe dane (klucze API, prywatne maile, ID czatów, ID projektów) zostały zamienione na placeholdery (`YOUR_...`) przed publikacją.
